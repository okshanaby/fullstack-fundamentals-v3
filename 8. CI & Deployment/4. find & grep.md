# Finding Things in Linux — Simple Summary

Linux provides powerful tools for searching files, directories, text inside files, and even running processes.

The two most common tools are:

* `find` → search for files and directories
* `grep` → search for text inside files or command output

---

## The `find` Command

The `find` command searches for files and directories based on criteria such as name, type, permissions, and more.

### Basic Syntax

```bash
find [location] [options]
```

Example:

```bash
find /bar -type f -name foo.txt
```

### Breakdown

```bash
find /bar -type f -name foo.txt
```

* `find` → search command
* `/bar` → location to search
* `-type f` → search only files
* `-name foo.txt` → file name must match `foo.txt`

---

## Useful `find` Options

### Search by name

```bash
-name
```

Matches files/directories by name.

Example:

```bash
find . -name "*.txt"
```

Finds all `.txt` files in the current directory and subdirectories.

---

### Search by type

```bash
-type
```

Limits results to a specific type.

Common values:

```text
f = file
d = directory
l = symbolic link
```

Example:

```bash
find . -type d
```

Finds only directories.

---

### Find empty files/directories

```bash
-empty
```

Example:

```bash
find . -empty
```

Finds empty files and empty directories.

---

### Find executable files

```bash
-executable
```

Example:

```bash
find . -executable
```

Finds files that can be executed.

---

### Find writable files

```bash
-writable
```

Example:

```bash
find . -writable
```

Finds files you have permission to write to.

---

## Example 1: Find All Log Files

```bash
find /var/log/ -type f -name "*.log"
```

### Breakdown

* `/var/log/` → search location
* `-type f` → only files
* `-name "*.log"` → file names ending in `.log`

This finds all log files in `/var/log`.

---

## Example 2: Find Directories Named "log"

```bash
sudo find / -type d -name log
```

### Breakdown

* `sudo` → run with administrator privileges
* `/` → search the entire filesystem
* `-type d` → directories only
* `-name log` → directory name must be exactly `log`

---

## The `grep` Command

`grep` searches for text patterns inside files or command output.

### Basic Syntax

```bash
grep [options] "pattern" file
```

Example:

```bash
grep -i "jem" /var/file.txt
```

### Breakdown

* `grep` → search text
* `-i` → ignore uppercase/lowercase differences
* `"jem"` → text to search for
* `/var/file.txt` → file being searched

This matches:

```text
jem
Jem
JEM
JeM
```

---

## Useful `grep` Flag

### Ignore case

```bash
-i
```

Makes the search case-insensitive.

Example:

```bash
grep -i "error" app.log
```

Matches:

```text
error
ERROR
Error
eRrOr
```

---

## Searching Running Processes

You can combine commands using a pipe (`|`).

Example:

```bash
ps aux | grep node
```

### Breakdown

```bash
ps aux
```

Shows all running processes.

Flags:

```text
a = show processes from all users
u = display user information
x = include processes without terminals
```

The output is sent through the pipe:

```bash
|
```

Then:

```bash
grep node
```

Filters the results and shows only lines containing `node`.

This is commonly used to find running Node.js applications.

---

## The `zgrep` Command

`zgrep` searches inside compressed `.gz` files without needing to unzip them first.

### Syntax

```bash
zgrep "pattern" file.gz
```

Example:

```bash
zgrep "ERROR" app.log.gz
```

Searches for `ERROR` directly inside the compressed log file.

### Why use it?

Without `zgrep`:

```bash
gunzip app.log.gz
grep "ERROR" app.log
```

With `zgrep`:

```bash
zgrep "ERROR" app.log.gz
```

Much faster and more convenient.

## Key Concepts Questions

### What is the basic syntax of `find`?

```bash
find [location] [options]
```

Common pattern:

```bash
find [location] -type [type] -name [pattern]
```

---

### How can `grep` filter process output?

By piping command output into `grep`.

Example:

```bash
ps aux | grep node
```

This shows only processes containing the word `node`.

---

### What does `zgrep` do?

It searches inside compressed `.gz` files without requiring you to unzip them first.

## One-Sentence Summary

`find` locates files and directories based on criteria like name and type, `grep` searches for text within files or command output, and `zgrep` extends grep to search directly inside compressed files.
