# Basic Node.js Server — Simple Summary

This code creates a simple **HTTP server** using Node.js.

When a user visits the server, it:

1. Listens on port `3000`.
2. Reads the `index.html` file.
3. Sends the HTML file back to the browser.
4. Returns a `200 OK` status code.

## Full Code

```js id="mk0p88"
const http = require("http");
const fs = require("fs");

const PORT = 3000;

const server = http.createServer(function (req, res) {
  res.writeHead(200, { "content-type": "text/html" });

  fs.createReadStream("index.html").pipe(res);
});

server.listen(PORT);

console.log(`Server started on port ${PORT}`);
```

## How It Works

### Import Required Modules

```js id="g3x4i7"
const http = require("http");
const fs = require("fs");
```

* `http` → Creates the web server.
* `fs` → Reads files from the file system.

### Define the Port

```js id="jzvc2z"
const PORT = 3000;
```

The server will be available at:

```text id="8wy36n"
http://localhost:3000
```

### Create the Server

```js id="p7xznm"
const server = http.createServer(function (req, res) {
```

* `req` (request) contains information about the incoming request.
* `res` (response) is used to send data back to the browser.

### Send Response Headers

```js id="pf53z0"
res.writeHead(200, { "content-type": "text/html" });
```

* `200` = Success status code.
* `text/html` tells the browser that HTML content is being sent.

### Read and Send the HTML File

```js id="sq29iy"
fs.createReadStream("index.html").pipe(res);
```

* Opens `index.html` as a stream.
* Sends its contents directly to the browser.
* `pipe()` efficiently transfers the file to the response.

### Start the Server

```js id="jz2jft"
server.listen(PORT);
```

Starts listening for incoming requests on port `3000`.

### Log a Message

```js id="wdn4pb"
console.log(`Server started on port ${PORT}`);
```

Displays a message in the terminal when the server starts.

## Running the Server

Start the server with:

```bash id="4av4v0"

```

Example output:

```text id="4evbvn"

```

Then open:

```text id="j4v7k6"

```

in your browser to see the contents of `index.html`.

## Key Points

* `http` creates the web server.
* `fs` reads files from disk.
* `createReadStream()` streams a file efficiently.
* `pipe(res)` sends the file to the client.
* `listen()` starts the server.
* The server serves `index.html` whenever a request is received.
