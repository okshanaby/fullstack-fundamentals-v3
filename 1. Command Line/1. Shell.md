# Shells — Simple Summary

A **shell** is a program that lets you interact with your operating system using commands.

Common shells:

* `bash` — Bourne Again Shell (one of the most common shells)
* `zsh` — Z Shell, a more extensible and customizable version of bash

## Check Your Current Shell

You can see which shell you're using with:

```bash
echo $0
echo $SHELL
```

### Difference

* `echo $0` → shows the shell currently running your session.
* `echo $SHELL` → shows your default login shell.

## Shell Configuration Files

### Zsh

Configuration file:

```text
~/.zshrc
```

This file stores:

* Aliases
* Environment variables
* Custom shell settings
* Plugins and themes

### Bash

Configuration file:

```text
~/.bash_profile
```

This file stores:

* Startup commands
* Environment variables
* Shell customizations

## Reload Shell Configuration

After editing a shell configuration file, reload it without opening a new terminal:

```bash
source <shell config location>
```

Example:

```bash
source ~/.zshrc
```

or

```bash
source ~/.bash_profile
```

This applies the changes immediately.

## Commands Explained

### `echo $0`

Displays the shell process currently running.

Example output:

```bash
zsh
```

### `echo $SHELL`

Displays your default shell path.

Example output:

```bash
/bin/zsh
```

### `source`

Reads and executes commands from a file in the current shell session.

Example:

```bash
source ~/.zshrc
```

This reloads your Zsh configuration so changes take effect immediately.

## Quick Reference

| Shell | Config File       |
| ----- | ----------------- |
| bash  | `~/.bash_profile` |
| zsh   | `~/.zshrc`        |

**Key idea:** Your shell configuration file stores your custom settings, and `source` reloads those settings without needing to restart the terminal.
