# Server Setup — Simple Summary

A brand-new server should first be updated and restarted to make sure it is secure and running the latest software.

## Server Setup Checklist

1. Update software
2. Restart the server
3. Create a new user
4. Make the user a superuser (sudo user)
5. Enable login for the new user
6. Disable root login

---

## Step 1: Updating and Restarting

First, connect to your server using SSH:

```bash
ssh username@server_ip
```

This uses **SSH (Secure Shell)** to securely log into your remote server using the given username and server IP address.

---

Next, update your server package list:

```bash
sudo apt update
```

* `sudo` → runs the command with administrator (root) privileges
* `apt` → package manager used in Ubuntu/Debian systems
* `update` → refreshes the list of available packages from repositories

This ensures your server knows the latest available software versions.

---

Then upgrade installed packages:

```bash
sudo apt upgrade
```

* `sudo` → runs with admin privileges so system files can be modified
* `apt` → package manager
* `upgrade` → installs the newest versions of all currently installed packages

This applies the actual updates to your system.

---

Finally, restart the server:

```bash
sudo shutdown now -r
```

* `sudo` → required to restart the system
* `shutdown` → system power command (shutdown or reboot)
* `now` → executes immediately
* `-r` → tells the system to reboot instead of powering off

This restarts the server so all updates take effect properly.

---

## One-Sentence Summary

**SSH into the server, update packages with `apt update`, upgrade them with `apt upgrade`, then reboot using `shutdown now -r` so changes are applied.**
