# DNS & URLs — Simple Summary

**DNS (Domain Name System)** is the system that translates human-friendly domain names into IP addresses that computers can understand.

Without DNS, you would have to remember IP addresses instead of website names.

Example:

```text id="dns01"
google.com
     ↓
142.250.190.14
```

---

# What is DNS?

DNS stands for:

```text id="dns02"
DNS = Domain Name System
```

It acts like the Internet's phone book.

---

## Phone Book Analogy

Imagine looking up a friend's phone number:

```text id="dns03"
John Smith
    ↓
555-1234
```

DNS works similarly:

```text id="dns04"
google.com
    ↓
142.250.190.14
```

Instead of remembering IP addresses, we use domain names.

---

# What is a Nameserver?

A **Nameserver** stores DNS records and answers DNS lookup requests.

Its job is:

> Translate domain names into IP addresses.

---

## DNS Lookup Process

```text id="dns05"
Browser
    ↓
DNS Server
    ↓
Find IP Address
    ↓
Connect to Website
```

---

# DNS Records

DNS records store information about a domain.

---

## A Record

An **A Record** maps a domain name directly to an IPv4 address.

Example:

```text id="dns06"
frontendmasters.com
        ↓
104.26.4.205
```

---

### Concept

```text id="dns07"
Name → IP Address
```

---

## CNAME Record

A **CNAME (Canonical Name)** maps one name to another name.

Example:

```text id="dns08"
www.example.com
       ↓
example.com
```

---

### Concept

```text id="dns09"
Name → Name
```

Instead of pointing directly to an IP, it points to another domain.

---

# Lookup Nameservers

```bash id="dns10"
nslookup frontendmasters.com
```

### What it does

Looks up DNS information for a domain.

---

### Command Breakdown

* `nslookup` → DNS lookup tool
* `frontendmasters.com` → domain being queried

---

### Example Output

```text id="dns11"
Name: frontendmasters.com
Address: 104.26.4.205
```

---

# Lookup DNS Records

```bash id="dns12"
dig frontendmasters.com
```

### What it does

Displays detailed DNS information.

---

### Command Breakdown

* `dig` → Domain Information Groper
* `frontendmasters.com` → domain being queried

---

### Example Output

```text id="dns13"
;; ANSWER SECTION:
frontendmasters.com. 300 IN A 104.26.4.205
```

# Anatomy of a URL

URL stands for:

```text id="url01"
URL = Uniform Resource Locator
```

A URL tells the browser where a resource is located and how to access it.

---

## Example URL

```text id="url02"
https://blog.example.com/articles?id=10
```

---

## URL Components

### Visual Breakdown

```text id="url03"
https://blog.example.com/articles?id=10
        │      │       │        │
        │      │       │        └─ Query Parameter
        │      │       └────────── Path
        │      └────────────────── Domain
        └───────────────────────── Protocol
```

---

## Protocol

```text id="url04"
https://
```

Specifies how communication occurs.

Common examples:

```text id="url05"
https://
http://
ftp://
```

---

## Subdomain

```text id="url06"
blog.example.com
```

Subdomain:

```text id="url07"
blog
```

Used to organize services.

Examples:

```text id="url08"
blog.example.com
api.example.com
mail.example.com
```

---

## Domain

```text id="url09"
example.com
```

Domain name identifies the website.

---

## Top-Level Domain (TLD)

```text id="url10"
.com
```

Common TLDs:

```text id="url11"
.com
.org
.net
.edu
.io
```

---

## Path

```text id="url12"
/articles
```

Identifies a specific resource on the website.

Examples:

```text id="url13"
/products
/users
/blog
```

---

## Query Parameters

```text id="url14"
?id=10
```

Used to send extra information.

Example:

```text id="url15"
https://example.com/products?id=25
```

Here:

```text id="url16"
id = 25
```

---

# Full URL Example

```text id="url17"
https://blog.example.com/articles?id=10
```

Breakdown:

| Component       | Value     |
| --------------- | --------- |
| Protocol        | https     |
| Subdomain       | blog      |
| Domain          | example   |
| TLD             | com       |
| Path            | /articles |
| Query Parameter | id=10     |

---

# DNS Resolution Process

When you visit:

```text id="dns16"
https://frontendmasters.com
```

The process is:

```text id="dns17"
Browser
   ↓
DNS Lookup
   ↓
Nameserver
   ↓
IP Address Found
   ↓
Connect to Server
   ↓
Website Loads
```

# Common Rule

**Humans use domain names, computers use IP addresses, and DNS translates between the two.**

---

# One-Sentence Summary

**DNS acts like the Internet's phone book by translating domain names into IP addresses using records such as A records and CNAMEs, while URLs provide the complete address of a resource by combining protocol, domain, path, and optional query parameters.**
