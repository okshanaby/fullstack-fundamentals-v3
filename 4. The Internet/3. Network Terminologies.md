# Network Terminologies — Simple Summary

When computers communicate over a network, they use different protocols and standards to move data from one device to another. Understanding TCP, UDP, ICMP, and packets helps explain how the Internet works behind the scenes.

---

# Key Network Terms

| Term   | Full Meaning                                |
| ------ | ------------------------------------------- |
| TCP    | Transmission Control Protocol               |
| UDP    | User Datagram Protocol                      |
| ICMP   | Internet Control Message Protocol           |
| Packet | Smallest unit of data sent across a network |

---

# 1. TCP (Transmission Control Protocol)

**TCP** is a communication protocol designed for **reliable data transmission**.

Its main goal is:

> Make sure all data arrives correctly and completely.

---

## How TCP Works

Before sending data, TCP establishes a connection using a **Three-Way Handshake**.

### TCP Handshake

```text id="tcp01"
Client          Server

SYN      ──────►

        ◄────── SYN ACK

ACK      ──────►
```

Connection established ✔

---

## What the Handshake Means

### SYN

```text id="tcp02"
SYN = Synchronize
```

Client asks:

> "Can we start communicating?"

---

### SYN ACK

```text id="tcp03"
SYN ACK = Synchronize Acknowledge
```

Server replies:

> "Yes, I received your request."

---

### ACK

```text id="tcp04"
ACK = Acknowledge
```

Client confirms:

> "Great, let's begin."

---

## Why TCP is Reliable

TCP keeps track of packets.

If a packet is missing:

```text id="tcp05"
Packet 1 ✔
Packet 2 ✔
Packet 3 ❌ Missing
Packet 4 ✔
```

TCP automatically requests Packet 3 again.

This ensures complete delivery.

---

## Common TCP Uses

* Websites (HTTP/HTTPS)
* Email
* File downloads
* SSH connections
* Databases

These applications need accurate data delivery.

---

# 2. UDP (User Datagram Protocol)

**UDP** is designed for **speed instead of reliability**.

Unlike TCP:

* No handshake
* No packet verification
* No packet retransmission

---

## How UDP Works

```text id="udp01"
Client ──────► Server
Client ──────► Server
Client ──────► Server
```

Packets are simply sent.

---

## Packet Loss Example

```text id="udp02"
Packet 1 ✔
Packet 2 ✔
Packet 3 ❌ Lost
Packet 4 ✔
```

UDP ignores the missing packet and continues.

---

## Why UDP is Faster

Because it doesn't spend time:

* Creating connections
* Confirming delivery
* Resending lost packets

---

## Common UDP Uses

* Video streaming
* Music streaming
* Online gaming
* Voice calls
* Video calls

Losing a few packets usually isn't noticeable.

---

## TCP vs UDP

| Feature                  | TCP      | UDP            |
| ------------------------ | -------- | -------------- |
| Reliable                 | ✔ Yes    | ❌ No           |
| Connection Required      | ✔ Yes    | ❌ No           |
| Packet Verification      | ✔ Yes    | ❌ No           |
| Retransmits Missing Data | ✔ Yes    | ❌ No           |
| Speed                    | Slower   | Faster         |
| Best For                 | Accuracy | Real-Time Data |

---

# 3. ICMP (Internet Control Message Protocol)

**ICMP** is used for network diagnostics and error reporting.

It helps devices answer questions such as:

* Is this server reachable?
* How long does communication take?
* Is there a network problem?

---

## Common Tools Using ICMP

### Ping

```bash id="icmp01"
ping google.com
```

Checks whether a server is reachable.

---

### Traceroute

```bash id="icmp02"
traceroute google.com
```

Shows the path taken to reach a destination.

---

## ICMP Example

```text id="icmp03"
Computer
    ↓
ICMP Echo Request
    ↓
Server
    ↓
ICMP Echo Reply
```

This is how `ping` works.

---

## Why ICMP is Useful

* Network troubleshooting
* Connectivity testing
* Route discovery
* Error reporting

---

# 4. Packets

A **packet** is the smallest unit of data sent across a network.

Large files are broken into many packets.

---

## Example

Suppose you send a large file:

```text id="pkt01"
movie.mp4
```

The network splits it into:

```text id="pkt02"
Packet 1
Packet 2
Packet 3
Packet 4
Packet 5
...
```

Each packet travels independently.

---

## Packet Journey

```text id="pkt03"
Computer
    ↓
Router
    ↓
ISP
    ↓
Internet
    ↓
Server
```

---

## Why Packets Exist

Benefits:

* Faster transmission
* Better reliability
* Easier routing
* Efficient network usage

---

## Packet Reassembly

When packets arrive:

```text id="pkt04"
Packet 1
Packet 2
Packet 3
Packet 4
```

The receiving device reconstructs the original file.

---

# Real-World Example

Watching a YouTube video:

```text id="real01"
Video
   ↓
Thousands of Packets
   ↓
Internet
   ↓
Your Device
```

Usually transmitted using UDP-based streaming technologies because speed matters more than perfect delivery.

---

# Common Rule

**All network communication is ultimately transmitted as packets, while TCP, UDP, and ICMP define different ways those packets are handled.**

---

# One-Sentence Summary

**TCP provides reliable communication through connection establishment and packet verification, UDP prioritizes speed for real-time applications, ICMP supports network diagnostics through tools like ping and traceroute, and packets are the small units of data that make all network communication possible.**
