# Creating WebSocket Connection — Simple Summary

A WebSocket connection in the browser is created by dynamically choosing the correct protocol (`ws://` or `wss://`) based on whether the page is running on HTTP or HTTPS, then using the `WebSocket` object with the current host. Incoming messages are handled using the `onmessage` event.

---

## Key Points

* Use `window.location.protocol` to determine whether the page is using HTTP or HTTPS.
* Select:

  * `ws://` for HTTP connections (typically port 80)
  * `wss://` for HTTPS connections (typically port 443)
* Create a WebSocket connection using `new WebSocket()`.
* The connection uses the current host via `window.location.host`.
* Handle incoming messages using the `onmessage` event handler.
* Access received data using `event.data`.

---

## WebSocket Protocols

* **ws://**

  * Used for HTTP connections
  * Typically runs on port 80

* **wss://**

  * Used for HTTPS connections
  * Typically runs on port 443

---

## Dynamic Protocol Selection

To ensure the WebSocket works for both HTTP and HTTPS:

* Use `window.location.protocol`
* If HTTPS → use `wss://`
* Otherwise → use `ws://`

---

## Key Steps to Create a WebSocket Connection

1. Determine the protocol (`ws://` or `wss://`)
2. Create a new `WebSocket` object
3. Specify the connection host
4. Set up an `onmessage` event handler to process incoming messages

---

## Example Code

```html
<html>
    <head></head>
    <body>
        Hello from websocket
    </body>

    <script>
        const protocol = window.location.protocol === 'https:' ? 'wss' : 'ws'
        const ws = new WebSocket(`${protocol}://${window.location.host}`)

        ws.onmessage = event => console.log(event.data)
    </script>
</html>
```

---

## How Incoming Messages Are Handled

* Use the `onmessage` event handler
* It receives an `event` parameter
* The message data is accessed via `event.data`

Example:

```javascript
ws.onmessage = event => console.log(event.data)
```

---

## One-Sentence Summary
