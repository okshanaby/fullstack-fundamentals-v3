# Implementing HTTPS with Certbot — Simple Summary

**Certbot** is a free tool that automatically obtains and installs **SSL/TLS certificates** (from Let's Encrypt) so your website can use **HTTPS**. It can also automatically configure **Nginx** and renew certificates before they expire.

## Steps to Enable HTTPS

### 1. Install and Use Certbot

Visit the official Certbot website:

```text
https://certbot.eff.org/
```

On the website:

1. Select your web server:

   * **Nginx**
2. Select your operating system:

   * **Linux (Snap)**

The website will then provide step-by-step instructions, which typically include:

* Installing **Snapd**
* Removing any old Certbot installation (if necessary)
* Installing Certbot
* Preparing the Certbot command
* Running Certbot to:

  * Obtain an SSL certificate
  * Automatically configure your Nginx server
* Testing automatic certificate renewal

After completing these steps, your website should be accessible over **HTTPS**.

---

### 2. Open the Firewall

Allow HTTPS traffic through the firewall.

```bash
sudo ufw allow https
```

This opens the standard HTTPS port so users can securely access your website.

---

### 3. Test Your Domain

After configuring HTTPS:

* Visit your website using:

```text
https://your-domain.com
```

* Check that:

  * The site loads successfully.
  * The browser shows a secure lock icon.
  * HTTP redirects to HTTPS (if configured).

---

# HTTPS Port

HTTPS uses the following default port:

| Protocol | Default Port |
| -------- | -----------: |
| HTTP     |         `80` |
| HTTPS    |        `443` |

---

# Commands

### Allow HTTPS Through the Firewall

```bash
sudo ufw allow https
```

**Explanation**

* `sudo` – Runs the command with administrator (root) privileges.
* `ufw` – **Uncomplicated Firewall**, a tool used to manage firewall rules on Linux.
* `allow` – Adds a firewall rule that permits incoming connections.
* `https` – Refers to the predefined HTTPS service (port **443**).

This command allows incoming HTTPS traffic to your server.

---

# Command Flags

There are **no command flags** used in the command above.

* `allow` is a **subcommand**, not a flag.
* The command does not use flags like `-y`, `-f`, or `--force`.

---

# Key Points

* **Certbot** automatically obtains and installs SSL/TLS certificates.
* It can automatically update your **Nginx** configuration for HTTPS.
* Certificates should be configured to **renew automatically** before they expire.
* The firewall must allow HTTPS traffic on **port 443**.
* After setup, always test your domain to ensure HTTPS is working correctly.

---

**Implementing HTTPS with Certbot involves installing Certbot, obtaining and automatically configuring an SSL certificate for Nginx, allowing HTTPS traffic through the firewall on port 443, and verifying that your website loads securely over HTTPS.**
