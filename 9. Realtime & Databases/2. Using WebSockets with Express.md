# Using WebSockets with Express — Simple Summary

**Express** handles normal HTTP requests, while the **`ws`** library adds WebSocket functionality for real-time communication. Instead of creating a separate server, you attach the WebSocket server to your existing Express HTTP server.

This allows your application to serve web pages with Express while also supporting real-time, two-way communication through WebSockets.

---

## Key Points

* The **`ws`** package is a popular and lightweight WebSocket library for Node.js.
* A WebSocket server can be attached directly to an existing Express HTTP server.
* The `clients.size` property returns the number of connected clients.
* You can create a custom `broadcast()` function to send messages to every connected client.
* Before sending data, always check that the client connection is still open.
* WebSocket connections have different states such as **Open**, **Closed**, and **Error**.

---

# Complete Example

```javascript
const express = require("express");
const server = require("http").createServer();

const app = express();

app.get("/", (req, res) => {
    res.sendFile("index.html", { root: __dirname });
});

server.on("request", app);

server.listen(3000, () => console.log("Websocket Server running on port 3000"));

/** Begin WebSocket Server Code */

const WebSocketServer = require("ws").Server;

const wss = new WebSocketServer({ server });

// Custom broadcast function
wss.broadcast = (data) => {
    wss.clients.forEach(client => {
        if (client.readyState === client.OPEN) {
            client.send(data);
        }
    });
};

wss.on("connection", (ws) => {

    const numOfClients = wss.clients.size;

    console.log("Connected clients:", numOfClients);

    wss.broadcast(`Current Visitors: ${numOfClients}`);

    // Client connected
    if (ws.readyState === ws.OPEN) {
        ws.send("Welcome to my server");
    }

    // Client disconnected
    ws.on("close", () => {

        const currentCount = wss.clients.size;

        wss.broadcast(`Current Visitors: ${currentCount}`);

        console.log("Client has disconnected. Remaining:", currentCount);
    });

});
```

# The `ws` Library

The **`ws`** package is one of the most popular WebSocket libraries for Node.js.

It provides an easy way to:

* Create WebSocket servers
* Accept client connections
* Send messages
* Receive messages
* Broadcast messages
* Track connected clients

---

# Attach WebSocket to the Existing Express Server

```javascript
const WebSocketServer = require("ws").Server;

const wss = new WebSocketServer({ server });
```

### Explanation

* `require("ws").Server`

  * Imports the WebSocket server class.

* `new WebSocketServer({ server })`

  * Attaches the WebSocket server to the existing HTTP server instead of creating another one.

This means:

* Express serves web pages.
* The same server also handles WebSocket connections.

---

# Creating a Broadcast Function

```javascript
wss.broadcast = (data) => {
    wss.clients.forEach(client => {
        if (client.readyState === client.OPEN) {
            client.send(data);
        }
    });
};
```

## Explanation

A **broadcast function** sends the same message to every connected client.

### Step-by-step

* `wss.clients`

  * A collection containing every connected WebSocket client.

* `.forEach()`

  * Loops through each connected client.

* `client.readyState === client.OPEN`

  * Ensures the connection is still open before sending data.

* `client.send(data)`

  * Sends the message to that client.

Without checking `readyState`, attempting to send to a disconnected client could cause errors.

# Listening for New Connections

```javascript
wss.on("connection", (ws) => {

});
```

## Explanation

The `"connection"` event runs every time a new client successfully connects to the WebSocket server.

The `ws` object represents that specific client connection.

# Getting the Number of Connected Clients

```javascript
const numOfClients = wss.clients.size;
```

## Explanation

`clients.size` returns the current number of connected WebSocket clients.

Example:

```text
1 client connected
clients.size = 1

Another client joins
clients.size = 2

One disconnects
clients.size = 1
```

---

# Sending a Message to Everyone

```javascript
wss.broadcast(`Current Visitors: ${numOfClients}`);
```

## Explanation

Every connected client immediately receives:

```text
Current Visitors: 5
```

This is useful for:

* Live visitor counters
* Chat rooms
* Notifications
* Multiplayer games

---

# Sending a Welcome Message

```javascript
if (ws.readyState === ws.OPEN) {
    ws.send("Welcome to my server");
}
```

## Explanation

If the client's connection is open, send a welcome message only to that client.

Example received by the client:

```text
Welcome to my server
```

Unlike `broadcast()`, `send()` only sends to one client.

---

# Detecting Client Disconnection

```javascript
ws.on("close", () => {

    const currentCount = wss.clients.size;

    wss.broadcast(`Current Visitors: ${currentCount}`);

    console.log("Client has disconnected. Remaining:", currentCount);

});
```

## Explanation

The `"close"` event runs when a client disconnects.

The server:

1. Counts the remaining clients.
2. Broadcasts the updated visitor count.
3. Logs the disconnection.

Example:

```text
Client has disconnected. Remaining: 3
```

# WebSocket Connection States

A WebSocket connection can be in one of several states.

## 1. Open (Ready)

The connection is active.

Messages can be sent and received.

```javascript
if (ws.readyState === ws.OPEN) {
    ws.send("Hello");
}
```

---

## 2. Closed

The connection has ended.

No more messages can be sent.

---

## 3. Error

Something went wrong with the connection.

Examples:

* Network failure
* Server crash
* Invalid connection

---

# Difference Between `send()` and `broadcast()`

| `send()`                      | `broadcast()`                                     |
| ----------------------------- | ------------------------------------------------- |
| Sends a message to one client | Sends the same message to every connected client  |
| Uses `ws.send()`              | Uses `wss.clients.forEach()` with `client.send()` |
| Private communication         | Public communication                              |

Imagine a chat application.

```text
Connected clients: 3
```

Everyone sees:


Alice receives:


Everyone immediately sees:

This happens without refreshing the page because WebSockets keep the connection open.

# Common Interview Questions

### Why is the `ws` library commonly used?

Because it provides a simple, lightweight, and straightforward way to implement WebSockets in Node.js.

---

### How do you attach a WebSocket server to an Express application?

Attach it to the existing HTTP server:

```javascript
const wss = new WebSocketServer({ server });
```

---

### How do you get the number of connected clients?

Use:

```javascript
wss.clients.size
```

---

### Why should you check `client.readyState` before sending a message?

To ensure the client's WebSocket connection is still open. Sending to a closed connection can result in errors.

---

### How do you send a message to every connected client?

Create a broadcast function that loops through `wss.clients` and calls `client.send()` for each connected client.
