# Database Overview — Simple Summary

A **database** is a system used to store, organize, and retrieve data efficiently. There are two main types of databases: **relational databases** and **non-relational (NoSQL) databases**. Relational databases organize data into structured tables, while NoSQL databases store data in more flexible formats.

---

## Key Points

* There are two main types of databases:

  * **Relational databases** (MySQL, SQLite, PostgreSQL)
  * **Non-relational databases** (NoSQL)

* Relational databases store data in **tables made up of rows and columns**.

* Each row represents a record, and each column represents a field.

* Data relationships are created using **primary keys and foreign keys**.

* SQL is used to query relational databases.

---

## Types of Databases

### Relational Databases

Examples:

* MySQL
* SQLite
* PostgreSQL

They use structured tables and strict schemas.

---

### Non-Relational Databases (NoSQL)

* More flexible structure
* Data is not strictly stored in tables
* Useful for unstructured or rapidly changing data

---

## Structure of a Relational Database

A relational database is built using:

* **Tables** → collections of data
* **Fields (Columns)** → define data types
* **Rows (Records)** → individual entries

---

## Primary Key

A **primary key** is a unique identifier for each row in a table.

* Must be unique
* Cannot be null
* Often an auto-increment number or a random hash

Example:

| id (Primary Key) | name |
| ---------------- | ---- |
| 1                | Jem  |
| 2                | Alex |

---

## Foreign Key

A **foreign key** is a field in one table that refers to the primary key in another table.

It is used to create relationships between tables.

Example:

* Users table → `id` (primary key)
* Orders table → `user_id` (foreign key referencing Users.id)

---

## SQL SELECT Statement

The basic SQL query used to retrieve data:

```sql
SELECT * FROM table_name WHERE condition;
```

### Example

```sql
SELECT * FROM users WHERE name = 'Jem';
```

---

## Explanation of SQL Components

* `SELECT *`

  * Selects all columns

* `FROM table_name`

  * Specifies which table to query

* `WHERE condition`

  * Filters results based on a condition

---

## One-Sentence Summary

**Databases store and organize data, with relational databases using tables connected by primary and foreign keys, and SQL used to query and retrieve that data.**
