# SQLite + WebSockets Integration — Simple Summary

**SQLite** is a lightweight, portable database that runs directly inside your application. It does not require a separate server, setup, or authentication system, making it ideal for small apps, prototypes, and embedded systems.

In this setup, SQLite is used together with a WebSocket server to track and store the number of connected users over time.

---

## Key Points (SQLite Basics)

* SQLite is **portable and self-contained**
* It runs **inside the application process**
* No need for database server setup or passwords
* Works across all platforms
* Useful for lightweight storage and logging

---

## In-Memory SQLite Database

```javascript
const db = new sqlite3.Database(':memory:');
```

### Meaning

* `:memory:` creates a temporary database stored in RAM
* Data is lost when the application stops
* Useful for testing or temporary storage

---

## `db.serialize()` Purpose

```javascript
db.serialize(() => {
    // database setup commands
});
```

### Meaning

* Ensures SQL commands run **in order**
* Guarantees tables are created before queries run
* Prevents race conditions during setup

---

## Security Rule (Important)

Never allow direct SQL queries from clients because:

* Clients could **drop tables**
* Clients could **read sensitive data**
* Clients could **modify or delete data**
* It creates major **security vulnerabilities**

## Database Structure

A table named `visitors` is created:

* `count` → number of connected users
* `time` → timestamp of the event

```sql
CREATE TABLE visitors (
    count INTEGER,
    time TEXT
);
```

## WebSocket + Database Integration

Each time a client connects, the system:

* Counts connected users
* Sends updates to all clients
* Stores the visitor count in SQLite with timestamp

## Full WebSocket + SQLite Code

```javascript
const express = require("express");
const server = require("http").createServer();

const app = express();

app.get("/", (req, res) => {
    res.sendFile("index.html", { root: __dirname });
});

server.on("request", app);

server.listen(3000, () =>
    console.log("Websocket Server running on port 3000")
);

/** Begin WebSocket Server Code */

const WebSocketServer = require("ws").Server;
const wss = new WebSocketServer({ server });

let isShuttingDown = false;

process.on('SIGINT', () => {
    if (isShuttingDown) return;
    isShuttingDown = true;

    console.log('\nGracefully shutting down...');

    wss.clients.forEach(function each(client) {
        client.close();
    });

    console.log('\nAll websockets client have been closed.\n');

    server.close(() => {
        shutdownDB();
    });
});

// Broadcast function
wss.broadcast = (data) => {
    wss.clients.forEach(client => {
        if (client.readyState === client.OPEN) {
            client.send(data);
        }
    });
};

wss.on("connection", (ws) => {

    const numOfClients = wss.clients.size;
    console.log("Connected clients:", numOfClients);

    wss.broadcast(`Current Visitors: ${numOfClients}`);

    if (ws.readyState === ws.OPEN) {
        ws.send("Welcome to my server");
    }

    db.run(`INSERT INTO visitors (count, time)
        VALUES (${numOfClients}, datetime('now'))
    `);

    ws.on("close", () => {
        const currentCount = wss.clients.size;

        wss.broadcast(`Current Visitors: ${currentCount}`);

        console.log("Client has disconnected. Remaining:", currentCount);
    });
});

/** End WebSocket Server */

/** Begin Database */

const sqlite = require('sqlite3');
const db = new sqlite.Database(':memory:');

db.serialize(() => {
    db.run(`
        CREATE TABLE visitors (
            count INTEGER,
            time TEXT
        )
    `);
});

function getCounts() {
    db.each("SELECT * FROM visitors", (err, row) => {
        console.log(row);
    });
}

function shutdownDB() {
    console.log('Shutting down db');

    getCounts();
    db.close();
}
```

---

## Explanation of Key Parts

### 1. Storing Visitor Data

```javascript
db.run(`INSERT INTO visitors (count, time)
VALUES (${numOfClients}, datetime('now'))`);
```

* Stores current visitor count
* `datetime('now')` generates current timestamp
* Each connection is recorded

---

### 2. Graceful Shutdown (`SIGINT`)

```javascript
process.on('SIGINT', () => { ... });
```

### Meaning

* Runs when you press `Ctrl + C`
* Safely closes:

  * WebSocket clients
  * HTTP server
  * Database

---

### 3. Closing WebSocket Clients

```javascript
wss.clients.forEach(client => {
    client.close();
});
```

* Forces all connected clients to disconnect cleanly

---

### 4. Closing the Database

```javascript
db.close();
```

* Closes SQLite connection safely after logging data

---

### 5. Reading Stored Data

```javascript
db.each("SELECT * FROM visitors", (err, row) => {
    console.log(row);
});
```

* Reads each record one by one
* Prints stored visitor history

---

## Flow of the System

1. Server starts
2. SQLite table is created
3. Client connects via WebSocket
4. Server:

   * Counts users
   * Sends updates
   * Stores data in SQLite
5. On disconnect:

   * Updates count again
6. On shutdown:

   * Closes clients
   * Prints database records
   * Shuts down cleanly
