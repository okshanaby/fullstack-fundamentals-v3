# Operating Systems — Simple Summary

**An Operating System (OS)** is software that manages a computer's hardware and allows applications to run. Unix is a family of operating systems that influenced many modern systems, including Linux and macOS.

## The Three Main Unix Families

The three major subsets of the Unix operating system are:

1. **Solaris**
2. **Linux**
3. **BSD (Berkeley Software Distribution)**

These systems follow Unix principles while providing their own features and implementations.

## The Three Main Parts of a Unix Operating System

### 1. Programs / Utilities

These are tools that users run to perform tasks.

Examples include:

```bash
ls
cp
mv
grep
```

Utilities are designed to perform specific jobs and can often be combined together.

### 2. Kernel

The **kernel** is the core of the operating system.

It is responsible for:

* Managing memory
* Managing CPU resources
* Controlling hardware devices
* Managing files
* Managing processes

The kernel acts as a bridge between applications and hardware.

### 3. Everything is Either a File or a Process

One of Unix's most important ideas is:

> Everything is either a file or a process.

* A **file** stores data.
* A **process** is a program that is currently running.

Many system resources, including devices, are treated like files, making Unix simple and consistent.

## The Most Interesting Aspect of Unix

The most unique aspect of the Unix model is:

> Everything is either a file or a process.

Unix programs communicate through standard channels:

* **Standard Input (stdin)** – receives input
* **Standard Output (stdout)** – sends normal output
* **Standard Error (stderr)** – sends error messages

These follow the **POSIX standard**, which helps Unix programs work consistently across different Unix-like systems.

### Example

```text
Keyboard (stdin)
        ↓
    Program
      ↓   ↓
(stdout) (stderr)
```

## Why This Matters

Because Unix follows consistent rules:

* Programs can work together easily.
* Tools can be combined into powerful workflows.
* Automation becomes simpler.
* Systems are easier to understand and maintain.

## Unix Philosophy

A core Unix philosophy is:

> Everything is either a file or a process.

This simple idea helps keep Unix systems flexible and powerful.

## One-Sentence Summary

**Unix operating systems are built around programs/utilities, the kernel, and the principle that everything is either a file or a process, with programs communicating through standard input, output, and error channels defined by the POSIX standard.**

# Commands Mentioned

## `ls`

Lists files and directories.

```bash
ls
```

## `cp`

Copies files or directories.

```bash
cp file1.txt file2.txt
```

## `mv`

Moves or renames files.

```bash
mv oldname.txt newname.txt
```

## `grep`

Searches for text inside files.

```bash
grep "hello" file.txt
```

### Command Summary

* `ls` → List files and folders.
* `cp` → Copy files or folders.
* `mv` → Move or rename files.
* `grep` → Search for text in files.
