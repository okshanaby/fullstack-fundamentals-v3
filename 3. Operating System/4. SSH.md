# SSH (Secure Shell) — Simple Summary

**SSH (Secure Shell)** is a secure way to connect to remote computers (servers). It uses **public key cryptography** to ensure safe communication without exposing passwords.

---

## How SSH Works (Simple Idea)

```text id="ssh01"
Your Computer (Private Key 🔒)
        ↓ encrypts
     Internet
        ↓
Server (Public Key 🔓)
```

* You keep the **private key secret**
* The server uses your **public key**
* Communication becomes encrypted and secure

---

## What are the Two Parts of an SSH Key Pair?

SSH uses a **key pair**:

### 1. Public Key

* Can be shared openly
* Stored on the server
* Used to encrypt data

### 2. Private Key

* Must stay secret
* Stored on your computer
* Used to decrypt data

---

## Key Rule

```text id="ssh02"
Public Key  → shared
Private Key → secret (never share)
```

---

## Default Location of SSH Keys

By default, SSH keys are stored in:

```text id="ssh03"
~/.ssh/
```

This is inside your home directory.

Example:

```text id="ssh04"
/home/user/.ssh/
```

---

## SSH Key File Names

Typical files inside `.ssh`:

```text id="ssh05"
id_rsa        → private key
id_rsa.pub    → public key
```

### Important Rule:

* Private key → no extension
* Public key → ends with `.pub`

---

## How to Generate SSH Keys

### 1. Default Method

This creates keys in the default `.ssh` folder:

```bash id="ssh06"
ssh-keygen -t rsa -b 4096
```

Press Enter to accept default location:

```text id="ssh07"
~/.ssh/id_rsa
```

---

### 2. Custom Folder Method

You can create SSH keys in a specific folder:

```bash id="ssh08"
ssh-keygen -t rsa -b 4096 -f ~/.ssh/new-folder/my_key
```

This creates:

```text id="ssh09"
my_key      (private key)
my_key.pub  (public key)
```

---

## How to Connect to a Remote Server

Once your public key is added to the server, you connect using:

```bash id="ssh10"
ssh user@server_ip
```

Example:

```bash id="ssh11"
ssh ubuntu@192.168.1.10
```

If using a custom key:

```bash id="ssh12"
ssh -i ~/.ssh/my_key ubuntu@192.168.1.10
```

---

## Why Public Key Cryptography is Powerful

Public key cryptography is strong because:

* Anyone can use the **public key to encrypt data**
* Only the **private key can decrypt it**
* Even if someone intercepts messages, they cannot read them

---

## Key Benefits of SSH

* No need to send passwords over the network
* Strong encryption
* Very hard to hack or guess
* Secure remote server access
* Used in cloud servers, Git, and DevOps systems

---

## One-Sentence Summary

**SSH is a secure system for remote access that uses a public-private key pair, where the public key encrypts data and only the private key can decrypt it, making communication safe and passwordless.**
