# Version Control & Git — Simple Summary

This section explains what Git is, how it works internally, and how to securely connect a server to GitHub using **SSH keys**.

---

# What is Version Control?

**Version control** is a system that records changes to files over time so you can:

* Track history of changes
* Revert to previous versions
* Collaborate with others safely
* Avoid losing work

---

# What is Git?

**Git** is a distributed version control system created by Linus Torvalds.

It allows developers to:

* Save snapshots of code (commits)
* Work on multiple branches
* Merge changes from different sources
* Work offline and sync later

---

# How Git Works Internally

## Hashing Algorithm

Git uses:

```text
SHA-1
```

### What this means:

* Every commit is identified using a **SHA-1 hash**
* A hash is a unique fingerprint of data
* Even small changes produce a completely different hash

So Git stores history like:

```
commit → SHA-1 hash → snapshot of project
```

---

# SSH in GitHub Authentication

Instead of using passwords, Git uses **SSH keys** for secure authentication.

---

## What command generates an SSH key?

```bash
ssh-keygen
```

### What it does:

* Creates a pair of cryptographic keys:

  * Private key (kept on your machine)
  * Public key (shared with GitHub)

---

## Which key is added to GitHub?

👉 **Public key only**

### Why:

* Public key = safe to share
* Private key = must remain secret

---

## How to test SSH connection to GitHub

```bash
ssh -Tv git@github.com
```

### What it does:

* Tests authentication with GitHub
* Shows debug output (`-v` = verbose)
* Confirms SSH key is working

---

# Full Setup Flow (Server → GitHub via SSH)

---

## 1. Create SSH key on server

```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

You can name it:

```text
gh_key
```

---

## 2. Add SSH key to GitHub

Copy the **public key**:

```bash
cat ~/.ssh/gh_key.pub
```

Then add it to GitHub:

* GitHub → Settings → SSH Keys → Add new key

---

## 3. Add remote repository

```bash
git remote add origin git@github.com:username/repo.git
```

---

## 4. Force Git to use your SSH key

Edit SSH config:

```bash
vi ~/.ssh/config
```

Add:

```text
Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/gh_key
```

---

## 5. Fix file permissions (VERY IMPORTANT)

SSH is strict about security.

### Fix config permissions:

```bash
chmod 600 ~/.ssh/config
```

### Fix private key permissions:

```bash
chmod 600 ~/.ssh/gh_key
```

---

# Why permissions matter

* `600` means:

  * Only owner can read/write
  * Prevents other users from accessing your SSH keys

If permissions are wrong:

* SSH may refuse to use the key
* GitHub authentication will fail

---

# 6. Push code to GitHub

After setup:

```bash
git push -u origin main
```

---

# Final Mental Model

```
Your Server
   ↓
SSH Key (private)
   ↓ authentication
GitHub (public key stored there)
   ↓
Git operations (push/pull)
```

---

# One-Sentence Summary

**Git is a version control system that tracks code changes using SHA-1 hashes, and when combined with SSH keys, it allows secure passwordless communication between your server and GitHub for pushing and pulling code.**
