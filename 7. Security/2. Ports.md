
# Ports — Simple Summary

This section explains what **network ports** are, why they matter, and how to use **Nmap** to discover open ports on a server.

---

# What is a Port in Networking?

A **port** is a communication endpoint used by network services.

Think of it like:

> One IP address = one house
> Ports = different doors for different services

So one server (IP) can run multiple services at the same time using different ports.

---

## How it works

```text id="port-model"
IP Address (Server)
   ├── Port 22 → SSH
   ├── Port 80 → HTTP
   ├── Port 443 → HTTPS
   └── Port 3000 → Node.js app
```

---

# Why Ports are Important

Ports allow:

* Multiple services on one server
* Organized traffic routing
* Separation of services (web, SSH, APIs)

Without ports, only one service could run per server.

---

# Well-Known Ports and Services

| Port | Service                    |
| ---- | -------------------------- |
| 22   | SSH (remote access)        |
| 21   | FTP (file transfer)        |
| 80   | HTTP (web traffic)         |
| 443  | HTTPS (secure web traffic) |

---

## View known ports on Linux

```bash id="ports1"
less /etc/services
```

### What it shows:

* List of registered ports
* Associated service names
* System-level reference file

---

# What is Port Collision?

**Port collision** happens when two services try to use the same port.

Example:

* Node.js tries to use port 3000
* Another app already uses 3000
* Conflict occurs → one service fails

---

## How to avoid it

Use less common ports:

* 3000
* 8000
* 8080
* 5000

---

# What is Nmap?

**Nmap (Network Mapper)** is a tool used to scan servers and discover:

* Open ports
* Running services
* Service versions
* Security exposure

---

# Install Nmap

```bash id="nmap1"
sudo apt install nmap
```

---

# Basic Port Scan

```bash id="nmap2"
nmap <your_server_ip>
```

### What it does:

* Scans common ports
* Shows which ports are open
* Identifies exposed services

---

# Advanced Scan (Service Version Detection)

```bash id="nmap3"
nmap -sV <your_server_ip>
```

### What it adds:

* Detects software running on each port
* Shows version numbers
* Helps identify vulnerabilities

---

# Why Nmap is Useful

* Security auditing
* Finding exposed services
* Checking firewall configuration
* Detecting misconfigured servers

---

# Security Insight

Open ports = potential attack surface

So:

* Only open necessary ports
* Close unused services
* Use firewall rules to restrict access

---

# One-Sentence Summary

**Ports are communication channels that allow multiple services to run on one server, and Nmap is a tool used to scan a server and identify which of these ports are open, helping you understand and secure your system.**
