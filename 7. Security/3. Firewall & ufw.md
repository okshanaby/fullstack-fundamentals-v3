# Firewall & UFW — Simple Summary

This section explains what a **firewall is**, how **UFW (Uncomplicated Firewall)** simplifies firewall management on Linux, and how to safely configure basic rules to secure a server.

---

# What is a Firewall?

A **firewall** is a security system that:

* Monitors incoming and outgoing network traffic
* Decides whether to **allow or block traffic**
* Works based on predefined security rules

### Simple idea:

```text id="firewall-model"
Internet Traffic → Firewall → Allowed / Blocked → Server
```

So it acts like a **security gatekeeper** for your server.

---

# What is UFW?

**UFW (Uncomplicated Firewall)** is a tool that makes firewall management easier on Linux.

Instead of using complex tools like `iptables`, UFW provides simple commands.

👉 It simplifies firewall rule creation and management.

---

# Why UFW is used

* Easy to configure
* Beginner-friendly
* Safer than manual firewall rules
* Reduces mistakes in configuration

---

# Basic UFW Setup Commands

These are the typical first steps when setting up a server firewall:

## 1. Check firewall status

```bash id="ufw1"
sudo ufw status
```

### What it does:

* Shows if firewall is active
* Displays current rules

---

## 2. Allow SSH (IMPORTANT)

```bash id="ufw2"
sudo ufw allow ssh
```

### Why this matters:

* Keeps remote access to your server
* Prevents lockout

⚠️ Never block SSH unless you have another access method.

---

## 3. Allow HTTP traffic

```bash id="ufw3"
sudo ufw allow http
```

### What this allows:

* Web traffic on port 80
* Public access to your website

---

## 4. Enable firewall

```bash id="ufw4"
sudo ufw enable
```

### What this does:

* Activates firewall rules
* Starts enforcing security policies

---

# Default Open Ports in Basic Setup

When configuring a basic firewall, usually:

* Port 22 → SSH
* Port 80 → HTTP

These are typically allowed for both:

* IPv4
* IPv6

---

# `ufw deny` vs `ufw reject`

## `ufw deny`

* Blocks traffic
* Sends a response (error message)
* Makes it obvious the port is blocked

## `ufw reject`

* Blocks traffic silently
* No response is sent back
* More secure in some cases (e.g. reduces scanning effectiveness)

---

### Simple comparison:

```text id="deny-reject"
deny   → "Access denied" response
reject → "No response at all"
```

---

# Blocking HTTP Example

To block all HTTP traffic:

```bash id="ufw5"
sudo ufw reject http
```

---

# Why firewall configuration is important

Because incorrect setup can:

* Block access to your server
* Lock you out permanently
* Break deployed applications

---

# Critical Warning (Very Important)

⚠️ Never disable or block SSH (port 22) unless:

* You have physical access to the server, OR
* You have another access method configured

Otherwise:

> You can lose access to your server completely

---

# One-Sentence Summary

**UFW is a simple Linux firewall tool that controls incoming and outgoing traffic using rules like allow, deny, and reject, helping secure a server while ensuring only necessary ports like SSH and HTTP remain open.**
