
# Permissions & `chmod` — Simple Summary

This section explains how file permissions work in Linux, how they are structured, and how the `chmod` command is used to control access to files and directories.

---

# What are `rwx` permissions?

In Linux, every file or directory has three basic permissions:

* `r` → read
* `w` → write
* `x` → execute

### Meaning:

* **read (r)** → view file content
* **write (w)** → modify file content
* **execute (x)** → run file as a program/script

---

# How permissions are structured

Permissions are divided into three groups:

```text id="perm-groups"
Owner   | Group   | Others (Everyone else)
```

Each group gets its own `rwx` settings.

### Example:

```text id="perm-example"
-rwxr-xr--
```

Breakdown:

* Owner → rwx (full access)
* Group → r-x (read + execute)
* Others → r-- (read only)

---

# Octal (Numeric) Permission System

Linux also represents permissions using numbers.

## Permission values:

* `r` = 4
* `w` = 2
* `x` = 1

---

## How it works

You add values together:

| Permission | Value     |
| ---------- | --------- |
| rwx        | 7 (4+2+1) |
| rw-        | 6 (4+2)   |
| r-x        | 5 (4+1)   |
| r--        | 4         |

---

# What does `chmod 600` mean?

```bash id="chmod600"
chmod 600 file.txt
```

### Breakdown:

* Owner → 6 = read + write
* Group → 0 = no permissions
* Others → 0 = no permissions

### Result:

```text id="perm600"
rw-------
```

### Meaning:

* Only the owner can read and write
* No one else has any access

---

# What is `chmod`?

`chmod` = change mode (change file permissions)

It controls who can:

* Read a file
* Modify a file
* Execute a file

---

# Principle of Least Privilege

This is a core security rule.

👉 Users should only have the **minimum permissions needed** to do their job.

---

## Why this is important

* Reduces risk of accidental changes
* Limits damage if an account is compromised
* Improves system security overall

---

# Real-world mindset

Instead of:

> “Give everyone access just in case”

You do:

> “Give only what is necessary — nothing more”

---

# One-Sentence Summary

**Linux file permissions control who can read, write, or execute files using rwx rules and numeric values, and `chmod` is used to enforce strict access control based on the principle of least privilege to improve system security.**
