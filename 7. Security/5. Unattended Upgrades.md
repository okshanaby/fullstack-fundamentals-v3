# Unattended Upgrades — Simple Summary

This section explains how Linux servers can automatically install security updates using **unattended-upgrades**, helping reduce vulnerabilities caused by outdated software.

---

# Why System Updates Matter

The biggest security risk in servers is:

> ❌ Not updating software regularly

### Why this is dangerous:

* Old software has known vulnerabilities
* Attackers actively scan for unpatched systems
* Many breaches happen due to missing updates

---

# What is `unattended-upgrades`?

**`unattended-upgrades`** is an Ubuntu package that automatically installs system updates in the background.

👉 It helps keep your server secure without manual intervention.

---

# What should be automatically updated?

Best practice is to only auto-install:

* Stable updates
* Security patches
* Long-Term Support (LTS) packages

### Why LTS?

* More stable
* Tested over time
* Less likely to break production systems

---

# Install Unattended Upgrades

```bash id="auto1"
sudo apt install unattended-upgrades
```

### What this does:

* Installs the auto-update system
* Prepares server for automatic security updates

---

# Enable Unattended Upgrades

```bash id="auto2"
sudo dpkg-reconfigure --priority=low unattended-upgrades
```

### What this does:

* Enables automatic updates
* Configures system update behavior
* Activates scheduled security patches

---

# How it works (behind the scenes)

```text id="auto-flow"
Ubuntu system
   ↓
Checks for updates daily
   ↓
Downloads security patches
   ↓
Installs automatically
   ↓
Keeps system secure
```

---

# Why this is important

Without unattended upgrades:

* You must manually update the server
* Security patches may be missed
* Server becomes vulnerable over time

With it:

* System stays continuously patched
* Less maintenance effort
* Lower risk of exploitation

---

# One-Sentence Summary

**Unattended upgrades automatically install security and stable system updates on Ubuntu servers, reducing the risk of attacks caused by outdated software and ensuring the system stays patched and secure.**
