# Application Setup (Node.js) — Simple Summary

After setting up your server and web server (Nginx), the next step is to install Node.js, create an application directory, enable version control with Git, and build a basic Node.js server.

## Request Flow

```text id="r5iq0v"
Browser Request
       ↓
      Nginx
       ↓
    Node.js App
       ↓
    Response
```

Nginx receives incoming requests and forwards them to your Node.js application.

---

## Installing Required Software

### 1. Add the Node.js Repository

```bash id="vdu4ea"
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
```

* `curl` → downloads content from a URL
* `https://deb.nodesource.com/setup_lts.x` → NodeSource setup script for Node.js latest
* `|` → pipes the downloaded script into another command
* `sudo` → runs the command with administrator privileges
* `-E` → preserves the current user's environment variables
* `bash` → executes the script using the Bash shell
* `-` → tells Bash to read the script from standard input

This adds the Node.js package source to your server.

---

### 2. Install Node.js

```bash id="h4o4v3"
sudo apt-get install nodejs
```

* `sudo` → run as administrator
* `apt-get` → package management tool
* `install` → install a package
* `nodejs` → Node.js runtime package

This installs Node.js on the server.

---

### 3. Install Git

```bash id="g7mbjh"
sudo apt install git
```

* `sudo` → run as administrator
* `apt` → package manager
* `install` → install package
* `git` → version control system

Git will be used to track application changes and manage source code.

---

## Setting Up the Application Directory

### 1. Change Ownership of `/var/www`

```bash id="wnjn8g"
sudo chown -R $USER:$USER /var/www
```

* `sudo` → run as administrator
* `chown` → change file ownership
* `-R` → recursively apply to all files and folders
* `$USER:$USER` → current user becomes owner and group owner
* `/var/www` → web application directory

This gives your user permission to manage files inside `/var/www`.

---

### 2. Create an Application Directory

```bash id="x0c1bi"
mkdir /var/www/app
```

* `mkdir` → make directory
* `/var/www/app` → new application folder

This creates a folder for your Node.js application.

---

### 3. Initialize a Git Repository

```bash id="iv6j8w"
git init
```

* `git` → version control tool
* `init` → create a new Git repository

Run this inside the application directory.

This allows Git to track your project files.

---

## Creating the Node.js Application

### 1. Create the Application File

```bash id="d8x7z0"
touch app.js
```

* `touch` → create an empty file
* `app.js` → main application file

This creates the Node.js entry point.

---

### 2. Initialize the Project

```bash id="x45r6v"
npm init
```

* `npm` → Node Package Manager
* `init` → create a new Node.js project

This generates a `package.json` file containing project information and dependencies.

---

### 3. Create a Basic Node.js Server

```js
const http = require("http");

http.createServer(function (req, res) {
  res.write("On the way to being a full stack engineer!");
  res.end();
}).listen(3000);

console.log("Server started on port 3000");
```

### How It Works

```js
const http = require("http");
```

Imports Node.js's built-in HTTP module.

```js
http.createServer(...)
```

Creates a web server.

```js
function (req, res)
```

* `req` → incoming request object
* `res` → outgoing response object

```js
res.write("On the way to being a full stack engineer!");
```

Sends text back to the browser.

```js
res.end();
```

Ends the response.

```js
.listen(3000);
```

Starts the server and listens for requests on port **3000**.

```js
console.log(...)
```

Displays a message in the terminal when the server starts.

---

### 4. Start the Application

```bash id="lr9mjh"
node app.js
```

* `node` → Node.js runtime
* `app.js` → application file to execute

This starts the server.

You can now access it at:

```text id="0rjlwm"
http://YOUR_SERVER_IP:3000
```

---

## One-Sentence Summary

**Install Node.js and Git, create an application directory with Git version control, initialize a Node.js project, build a simple HTTP server in `app.js`, and run it using `node app.js` on port 3000.**
