# Web Servers & Nginx — Simple Summary

A **web server** receives requests from users (browsers) and routes them to the correct destination, such as a website, application, database, or another server.

## Common Web Servers

The two main web servers discussed are:

* **Nginx** (pronounced "Engine-X")
* **Apache**

## What Nginx Does

Nginx can act as:

* A **Web Server** — serves websites and static files
* A **Reverse Proxy** — receives requests and forwards them to backend applications
* A **Forward Proxy** — acts on behalf of clients when making requests

### Request Flow

```text
Browser Request
       ↓
      Nginx
       ↓
 Application / Database / Another Server
       ↓
    Response
```

Nginx sits in front of your application and decides where requests should go.

## Installing Nginx

### 1. Install Nginx

```bash
sudo apt install nginx
```

* `sudo` → run command with administrator privileges
* `apt` → package manager for Ubuntu/Debian
* `install` → installs a package
* `nginx` → the Nginx web server package

This downloads and installs Nginx on the server.

---

### 2. Start Nginx

```bash
sudo service nginx start
```

* `sudo` → run as administrator
* `service` → manage system services
* `nginx` → the Nginx service
* `start` → start the service

This launches the Nginx web server.

---

### 3. Open Your Server in a Browser

Visit:

```text
http://YOUR_SERVER_IP
```

If Nginx is running correctly, you'll see the default Nginx welcome page.

---

## Default Website Location

The default Nginx website files are stored in:

```text
/var/www/html
```

This is known as the **document root**.

Any files placed here can be served by Nginx.

Example:

```text
/var/www/html
├── index.html
└── other-files
```

---

## Nginx Configuration Directory

Nginx configuration files are typically located in:

```text
/etc/nginx/
```

This directory contains the server settings and website configurations.

---

## Viewing the Default Configuration

```bash
less /etc/nginx/sites-available/default
```

* `less` → view a file without editing it
* `/etc/nginx/sites-available/default` → default Nginx site configuration

This allows you to inspect the default website configuration.

---

## Basic Nginx Configuration

Example:

```nginx
root /var/www/html;

index index.html index.htm index.nginx-debian.html;

server_name _;

location / {
    try_files $uri $uri/ =404;
}
```

---

### `root`

```nginx
root /var/www/html;
```

The **root directive** defines the base directory where Nginx looks for website files.

Example:

```text
Request:
http://example.com/index.html

Nginx looks in:
 /var/www/html/index.html
```

---

### `index`

```nginx
index index.html index.htm index.nginx-debian.html;
```

This tells Nginx which file to serve when a user visits a directory.

Example:

```text
User visits:
http://example.com/

Nginx tries:
1. index.html
2. index.htm
3. index.nginx-debian.html
```

---

### `server_name`

```nginx
server_name _;
```

Defines which domain names this configuration responds to.

The underscore (`_`) acts as a catch-all server name.

---

### `location` Block

```nginx
location / {
    ...
}
```

A **location block** defines how requests for a particular URL path should be handled.

```text
/          → all requests
/images    → image requests
/api       → API requests
```

The `/` location matches everything under the website.

---

### `try_files` Directive

```nginx
try_files $uri $uri/ =404;
```

This tells Nginx how to find the requested resource.

Nginx tries:

1. `$uri` → exact file
2. `$uri/` → directory
3. `=404` → return a 404 error if nothing exists

Example:

```text
Request:
http://example.com/about

Try:
1. /var/www/html/about
2. /var/www/html/about/
3. Return 404
```

---

## Important Terms

### Directive

A directive is a single Nginx instruction.

Example:

```nginx
try_files $uri $uri/ =404;
```

`try_files` is a directive.

---

### Location Block

A location block groups directives that apply to specific URL paths.

Example:

```nginx
location / {
    try_files $uri $uri/ =404;
}
```

Everything inside the braces belongs to that location.

---

## One-Sentence Summary

**Nginx is a web server and proxy that routes incoming requests, serves files from a document root such as `/var/www/html`, and uses configuration directives like `root`, `location`, and `try_files` to determine how requests are handled.**
